# Dashboard Feature Module

Implements **Dashboard** (SRS Section 10.5; SAD Section 8.3).

**Purpose:** The consolidated home screen: Daily Summary, Quick Actions, Recent Activities, Statistics, and Navigation.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
