# Notification System Feature Module

Implements **Notification System** (SRS Section 10.17; SAD Section 8.14).

**Purpose:** Notification preferences, notification history, and Local/Push notification delivery.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
