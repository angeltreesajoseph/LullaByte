# Gallery Feature Module

Implements **Gallery** (SRS Section 10.12; SAD Section 8.13).

**Purpose:** Photo/video upload, timeline/grid views, search/filter, cloud backup, and offline storage.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
