# Feeding Tracker Feature Module

Implements **Feeding Tracker** (SRS Section 10.7; SAD Section 8.6).

**Purpose:** Breastfeeding, bottle, formula, and solid feeding logging with the Feeding Timer and Daily/Weekly/Monthly statistics.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
