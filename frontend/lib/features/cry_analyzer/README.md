# AI Cry Analyzer Feature Module

Implements **AI Cry Analyzer** (SRS Section 10.6; SAD Section 8.5).

**Purpose:** Cry recording/upload, AI-powered classification, confidence and probability display, recommendations, and prediction history.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
