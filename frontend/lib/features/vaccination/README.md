# Vaccination Management Feature Module

Implements **Vaccination Management** (SRS Section 10.10; SAD Section 8.9).

**Purpose:** The vaccination schedule, status tracking, appointment scheduling, and reminders.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
