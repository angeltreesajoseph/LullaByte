# Diaper Tracker Feature Module

Implements **Diaper Tracker** (SRS Section 10.9; SAD Section 8.8).

**Purpose:** Pee/poop/mixed/dry diaper logging with size, color, notes, timeline, and statistics.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
