# Baby Management Feature Module

Implements **Baby Management** (SRS Section 10.3 / 10.4 / 10.13; SAD Section 8.4 / 8.11).

**Purpose:** Baby registration, twin/multiple-birth registration, baby switching, and full baby profile management.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
