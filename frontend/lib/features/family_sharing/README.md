# Family Sharing Feature Module

Implements **Family Sharing** (SRS Section 10.20; SAD Section 8.18).

**Purpose:** Inviting family members/caregivers/doctors, role-based permission management, and shared baby records.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
