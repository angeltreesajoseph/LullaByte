# Milestone Tracking Feature Module

Implements **Milestone Tracking** (SRS Section 10.11; SAD Section 8.12).

**Purpose:** The developmental milestone timeline, expected-age guidance, and achievement recording with photo/video attachment.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
