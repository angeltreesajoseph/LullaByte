# Growth Records Feature Module

Implements **Growth Records** (SRS Section 10.14; SAD Section 8.10).

**Purpose:** Weight, height, and head circumference tracking, growth charts, and growth report export.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
