# Settings Feature Module

Implements **Settings** (SRS Section 10.21; SAD Section 8.17).

**Purpose:** Profile, theme, language, privacy, security, accessibility, backup/restore, data export, and account management.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
