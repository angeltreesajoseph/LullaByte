# Reports and Analytics Feature Module

Implements **Reports and Analytics** (SRS Section 10.16; SAD Section 8.15).

**Purpose:** Daily/weekly/monthly reports and per-module analytics, data visualization, and PDF/CSV export.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
