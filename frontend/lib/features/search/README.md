# Search Feature Module

Implements **Search** (SRS Section 10.19; SAD Section 8.19).

**Purpose:** Global/quick/advanced search, filters, sorting, and search history across all tracked data.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
