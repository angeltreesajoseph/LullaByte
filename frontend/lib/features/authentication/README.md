# Authentication Feature Module

Implements **Authentication** (SRS Section 10.1; SAD Section 8.2).

**Purpose:** User registration, login, Google Sign-In, Phone OTP, password reset, and session management.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
