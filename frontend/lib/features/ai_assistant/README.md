# AI Parenting Assistant Feature Module

Implements **AI Parenting Assistant** (SRS Section 10.15; SAD Section 8.16).

**Purpose:** The AI chat interface, parenting/feeding/sleep/vaccination/growth guidance, and conversation history.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
