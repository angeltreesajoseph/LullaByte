# Sleep Tracker Feature Module

Implements **Sleep Tracker** (SRS Section 10.8; SAD Section 8.7).

**Purpose:** Sleep session timing, day/night classification, and Daily/Weekly/Monthly sleep statistics.

Structured per Clean Architecture (SAD Section 6.1) into `presentation/`,
`application/`, `domain/`, and `data/` sub-layers, consistent with the
Feature-first Architecture (SAD Section 6.4).
