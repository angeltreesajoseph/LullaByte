# frontend

The Flutter mobile client for LullaByte, targeting Android and iOS from a
single codebase (SAD Section 5.2, NFR-PORT-01–03).

Implements Clean Architecture (SAD Section 6.1), a Feature-first module
layout (SAD Section 6.4), the MVVM pattern via Riverpod (SAD Section 6.3),
and the Repository Pattern (SAD Section 6.2) for all local (SQLite) and
remote (FastAPI, via Dio) data access.

Platform folders (`android/`, `ios/`, `web/`) and the `pubspec.yaml` project
manifest are intentionally not created yet — they will be generated by
`flutter create` / added during project initialization, together with the
actual Dart source files.
