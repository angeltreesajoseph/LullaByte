# models

SQLAlchemy ORM models, one per entity in the logical database schema (SAD
Section 9.3) — `User`, `Baby`, `FamilyMembership`, `FeedingSession`,
`SleepSession`, `DiaperChange`, `VaccinationSchedule`, `Milestone`,
`GrowthRecord`, `Media`, `CryPrediction`, `AssistantConversation`, and
related tables. Defines table structure and relationships only — no business
logic.
